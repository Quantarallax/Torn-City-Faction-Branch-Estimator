# Torn City Faction Branch Estimator
Calculate how long it would take to get enough specialist upgrades to open another branch, based on respect history for a faction.

Install into TamperMonkey https://www.tampermonkey.net/

## Overview
Ever wondered how long it would take to open another specialist bramch?

This script uses faction respect gain history to calculate how much respect your faction makes over a period of time. With that respect it can be calculated how long it will take to open the cheapest specialist upgrades to reach the number of upgrades needed to open another branch.

## Details
Enter how many upgrades are needed to get to open a new specialist branch.

Enter how many days faction respect history you want the script to look back at (this is useful if older entries skew the results e.g. your faction is gaining more respect per day now, than it was in the earlier days)

Show faction respect gains history to see daily accumulation of respect.

Show calculations made to come to the conlusions of x days left before a new faction special branch can be unlocked.

Obfurscate values for screenshots (mainly so I can take screenshots for the readme without showing faction figures!)
