# Torn City Faction Branch Estimator
Calculate how long it would take to get enough specialist upgrades to open another branch, based on respect history for a faction.

## Overview
Ever wondered how long it would take to open another specialist bramch?

This script uses faction respect gain history to calculate how much respect your faction makes over a period of time. With that respect it can be calculated how long it will take to open the cheapest specialist upgrades to reach the number of upgrades needed to open another branch.
